Informasi proyek

Komponen yang digunakan pada aplikasi.

Frontend

Nginx + HTML/CSS/JavaScript

Antarmuka berjalan di container terpisah dan mengakses backend melalui service name.

Backend

Python REST API

Menyediakan GET, POST, PUT, PATCH, dan DELETE untuk data tugas.

Penyimpanan

team-task-data

Named volume menyimpan tasks.json agar data tetap ada setelah container dibuat ulang.

Network

app-net

Custom bridge network menghubungkan container frontend dan backend.

Jenkins pipeline

Checkout→Syntax Check→Build Image→Deployment→Health Check

Status build sebenarnya diperiksa melalui Jenkins, bukan dibuat secara statis di halaman ini.
